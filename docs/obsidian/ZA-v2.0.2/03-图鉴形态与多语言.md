**注意：** `trpmcatalog` 是资源目录，不是经证实的完整图鉴或可捕获物种主表。

## 名称数据（简中）

`U/ik_message/dat/Simp_Chinese/common/` 中有：
- `monsname.dat/.tbl`：物种名；
- `pokedex.dat/.tbl`、`zukan_comment_A.dat/.tbl`、`zukan_comment_B.dat/.tbl`：图鉴 UI 和描述；
- `itemname.dat/.tbl`、`wazaname.dat/.tbl`、`typename.dat/.tbl`、`place_name.dat/.tbl`：道具、招式、属性、地点名称。

语言子目录已确认：`English`、`French`、`German`、`Italian`、`JPN`、`JPN_KANJI`、`Korean`、`LATAM`、`Simp_Chinese`、`Spanish`、`Trad_Chinese`。

## 提取顺序

1. 解资源目录 `trpmcatalog`，仅用于建立 `species/form/gender → 模型` 关系。
2. 为图鉴 `exl` 的 BIN 寻找匹配 schema/实际读取调用，确认 dex order、species、form 和 DLC/收录标志，不明字段留空。
3. 解密各语言 DAT，待消息 key 被验证后再 join 到具体物种；不能用 TBL/DAT 的数组下标直接配对。
4. 对多形态、普通、DLC 物种分别抽样回查。

导出 `species.csv`、`pokedex_entries.csv`、`forms.csv`、`localization.csv` 和 `unresolved_keys.csv`。基本字段 `version,internalSpeciesId,nationalId,formId,genderVariant,dexId,dexOrder,language,messageKey,text,sourcePath,sourceSha256,evidence`。
