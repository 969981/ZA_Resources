# Z-A 2.0.2 技能解析：wazaId、招式配置、学习表区别

> [!success] v2.0.2 原生 Personal 学习表已经真正解析
> 已从 `avalon/data/personal_array.bin` 的 FlatBuffers field 25 提取 **1,445 条物种/形态及 20,234 条学习记录**，并按 `wazaname.dat/tbl` 配出游戏的简体中文招式名称；其中 `learnLevelRaw=253` 有 412 条、`254` 有 294 条，均为特殊编码，不可当作普通等级。完整数据见 `_tables/battle/ZA_levelup_learnsets_zh.csv`，解析方法详见 [[28-中文名称与原生学习表实测]]。

> [!important] 不同的“技能表”不是一回事
> **遭遇的预置招式**、**训练家使用的 4 招**、**头目额外招式**、**招式的场景属性分类**、**物种的升级学习表/TM 兼容表**分别是不同资料。目前已进一步解码 **Personal 全量学习向量**；招式威力、PP、属性和类别现已从 `waza_array.bin` 的 902 条主记录解出；**实际效果、特殊命中编码和 TM 相容性**等仍需独立解析，不可与学习表混同。

## 一、主要招式数据来源

| 数据来源 | 数据量 | 重要字段 | 所代表的层次 |
|---|---:|---|---|
| `ZA_encounters_flat.csv` | 1,966 条遭遇 | `wazaListJson` | 某条遭遇配置的**预置招式 ID** |
| `ZA_trainer_parties.csv` | 8,005 个队伍槽 | `movesJson` | 训练家队伍每个槽的**招式配置** |
| `oyabun_waza.records.csv` | 371 条物种记录 | `devNo`、`formTableList[].wazaNo` | 头目相关**附加招式表** |
| `waza_attribute.records.csv` | 25 组 | `wazaAttributeId`、`wazaIdList[]` | 场景/招式**属性分类**，不是招式学习表 |
| `ZA_levelup_learnsets_zh.csv` | 20,234 条 | `speciesId/formNo/moveId/learnLevelRaw/unlockLevelRaw` | 原生 Personal 学习/解锁配置 |
| `ZA_move_stats_zh.csv` | 902 条 | `moveId/typeId/categoryId/powerRaw/accuracyRaw/ppRaw` | 真实招式主表，已关联中文名称；命中 101 是特殊编码 |

1,966 条遭遇中有 **264 条**显式含 `wazaListJson` 配置。其余空白不能解释成“没有技能”；游戏可能按物种等级或其它载入路径计算技能。

8,005 个训练家成员中，以 `movesJson.waza1..4.wazaId` 是否有显式值为准，可在 **2,192 条**队伍槽中看到至少一个非空招式 ID。其余槽位的 `{}` 不等于没有招式，也不自动意味着程序一定计算等级习得。

## 二、真实遭遇例子：原始 4 招是什么

`ect_boss_0359_01` 中：

```json
{
  "id": "ect_boss_0359_01",
  "devNo": 359,
  "minLevel": 25,
  "maxLevel": 25,
  "wazaList": {
    "waza1": 399,
    "waza2": 232,
    "waza3": 109,
    "waza4": 43
  }
}
```

能证明：这条**静态遭遇**给出了四个编号（399、232、109、43）。这条 Encounter 本身**没有**给出完整招式基础属性，但可以将 `waza1..4` 的 ID 与独立解析出的 `ZA_move_stats_zh.csv` 关联，得到中文名称、属性、分类、威力、命中与 PP；实际等级习得和 Plus/技能效果来自不同系统。要知道游戏实际产生对象是否保留这四招，需要查加载后代码是否覆盖。

## 三、训练家的技能结构与 `{}` 误读

`trainer.records.csv` 的一条配置可能出现：

```json
{
  "poke1": {
    "devId": 675,
    "level": 61,
    "waza1": {"wazaId": 280},
    "waza2": {"wazaId": 242},
    "waza3": {"wazaId": 418},
    "waza4": {"wazaId": 182, "isPlusWaza": true}
  }
}
```

- `poke1.devId` 是训练家第 1 个成员的物种编号，**不等于当前野生场景的 encounterId**。
- `wazaId=182` 是招式 ID。
- `isPlusWaza=true` 表示源对象显式写入技能 Plus 相关标志，具体效果需运行时验证。
- `isPlusWaza` 没被写入、`waza1={}` 并不一定等于“假”或“没有招式”——这是 FlatBuffers 默认字段可能省略的结果。

若 `ZA_trainer_parties.csv` 的 `movesJson` 太复杂，原始 `trainer.records.csv` 的 `row_json` 保留完整 `poke1..poke6` 子对象，有助于逐字段解读。

## 四、头目技能表如何联到物种

`battle/oyabun_waza.records.csv` 的 `row_json` 结构类似：

```json
{"devNo":1,"formTableList":[{"wazaNo":188}]}
```

又如 `devNo=3` 有原始的 `formNo` 和 `wazaNo=89` 条目。其用途和出现时机需要代码/场景证据核实。不能单凭一条 `wazaNo` 就断言这种宝可梦在任何地点都必定学会该招。

自动生成的 364 张 [[22-宝可梦数据档案索引|物种卡片]] 包含“头目额外招式原始记录”一节，会按 `devNo` 关联这一张表。

## 五、`WazaAttribute` 真的是“技能属性表”吗？

`waza_attribute.records.csv` 读出的：

```json
{"wazaAttributeId":"WazaCut","wazaIdList":[75,163]}
```

另有：

```json
{"wazaAttributeId":"WazaDestruction","wazaIdList":[2]}
```

这 25 个分类中共记录 **301 次招式 ID 引用**（不是 301 个不同可学习招式）。从 `WazaCut` 字段名可以提出“具有场景切割作用”的候选推测，但具体是否为战斗威力属性、地图技能触发条件或可用场景行为，需要查对应函数/资源；不能直接把它当作 `type`（属性相克类型）或 `learnset`（学习表）。

## 六、技能中文名：已经从本版 ROM 真实解密

已知游戏资源可定位：

```text
world/ik_data/field/waza_attribute/waza_attribute_data/waza_attribute_data.bin
ik_message/dat/Simp_Chinese/common/wazaname.dat
ik_message/dat/Simp_Chinese/common/wazaname.tbl
ik_message/dat/Simp_Chinese/common/wazainfo.dat
ik_message/dat/Simp_Chinese/common/wazainfo.tbl
```

当前已完成 `wazaname.tbl` 标签数字与 `wazaname.dat` UTF-16 解密文本的对应，得到 921 条原生简体中文招式名，并在 20,234 行学习表中直接关联。具体方法见 [[28-中文名称与原生学习表实测]]。

招式基础威力/属性/PP 已由 `avalon/data/waza_array.bin` 的原始 FlatBuffers 主表完成独立解码，详情见 [[30-招式主表威力命中与PP实测]]。若要验证招式效果与运行时修正，需：
1. 读取 `wazaname.tbl` 的编号/哈希/索引结构，解码其实际键。
2. 用 `wazaname.dat` 解码为真正的 Unicode 中文招式名。
3. 证明二进制 `wazaId` 如何对应消息表键，至少选几个明确的 ID 做交叉验证。
4. 使用 `wazainfo` 对比描述与名称的对应行序或键。
5. 才把 `wazaId=399` 等数值替换成中文名称。

不能仅因为外部游戏数据库中有第 399 号技能，就假设当前资源的编号映射绝对一致。

## 八、能马上跑的技能统计脚本

```python
import csv
import json
from pathlib import Path
root = Path("Unpack/v2.0.2/romfs/arc/data.trpfs/virtual_converted/_tables")
with (root / "encounters/ZA_encounters_flat.csv").open(
    encoding="utf-8-sig", newline=""
) as f:
    for r in csv.DictReader(f):
        if r["speciesId"] != "359":
            continue
        moves = json.loads(r["wazaListJson"] or "{}")
        print(r["encounterId"], r["minLevel"], r["maxLevel"], moves)
```

如果想看全物种，打开 [[22-宝可梦数据档案索引]] → 对应物种的笔记，查看“每条遭遇定义”“训练家队伍”和“头目额外招式”。这里展示的只是**这些配置显式记录的招式编号**，不是物种全部技能学习路线。
