## 证据等级

| 级别 | 定义 |
| --- | --- |
| E0 PATH | 仅确认路径、文件大小、哈希 |
| E1 STRUCTURE | schema/二进制合法解码，或仅完成 FlatBuffer 边界检查（必须注明区别） |
| E2 SEMANTIC | 字段、枚举、外键和游戏内表现一致 |
| E3 RUNTIME | v2.0.2 对应 Build ID 下的运行时读写/分支验证 |
| E4 REPRODUCED | 多场景复现及输出回读验收 |

不能将 `STRUCTURE_ONLY` 写作完整语义解析，不能将外部资料的地址写为已复现的 2.0.2 偏移。
