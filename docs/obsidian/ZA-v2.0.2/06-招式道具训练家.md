# 招式、道具、训练家与掉落

以 `U = Unpack/v2.0.2/romfs/arc/data.trpfs/virtual` 为根。

## 真实位置

| 内容 | U/相对路径 |
| --- | --- |
| 道具主表 | `world/exl/item_data/item_data/item_data.bin` |

`world/ik_data` 上述 BIN 均有同名 `.bfbs`；`world/exl` 的道具和商店主表暂无已核实的相邻 schema。

## 数据提取与匹配

1. 解密 `itemname / iteminfo / wazaname / wazainfo / trname / monsname` 的 DAT；解析 TBL 的 AHTB key/hash/name 并保留原始下标。TBL 和 DAT 不保证一一对应。
2. `flatc` 转换具备 BFBS 的数据，提取实际 `itemId` / `moveId` / `speciesId` 等候选关联键，先验证字段名和 ID 范围，再连接中文名称。
3. 对 `item_data.bin`、`shop_item_lineup.bin` 按 [[02-从TRPFS到JSON]] 的无 schema 路线调查，不能直接认为文本条数就是道具 ID 数量。
4. 训练家队伍通过真实战斗比对等级/道具/技能；掉落表通过击败与回读样本验证。
5. **升级习得表、技能池、技能机器兼容列表仍需单独定位。** `wazaname.dat` 是文本，不是 learnset；本轮没有捏造其原始路径。

导出 `moves.csv`、`items.csv`、`drops.csv`、`field_items.csv`、`shops.csv`、`trainer_parties.csv`、`localization.csv`、`unresolved-learnset.csv`。

每表包含 `sourcePath,sourceSha256,schemaPath,fieldPath,evidence`，对于未知字段保留原始编码。
