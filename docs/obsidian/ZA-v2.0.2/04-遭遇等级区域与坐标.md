## 关联链与验证

候选图：`encounter → spawner → transform → scene / zone → localized place`。**这不是已经确定的外键关系**。要用 JSON 中真实字段名、主键唯一性、JOIN 命中率与游戏内场景验证。

等级范围、遭遇权重、昼夜、天气、头目标志、剧情条件与 DLC 是**待查字段类别**。若实际等级由程序生成规则计算，不能因字段名字相似就直接认定是等级上下限。

游戏内采样：记录 Build ID、区域、时间、天气、物种/form、实际等级、头目状态与重置次数；跨多个场景验证候选 min/max、条件和刷新组。

导出 `encounter_rows.csv`：
`encounterId,spawnerId,transformId,sceneId,areaId,zoneId,locationId,speciesId,formId,minLevel,maxLevel,weight,conditions,sourcePath,schemaSha256,evidence`。

**地址必须分类**：地图位置写 `sceneId + (x,y,z)`；内存地址写 `main+RVA`，另见 [[07-ExeFS地址与动态验证]]。传送点需结合 `field_area_jump_point` 和实际游戏跳转核对。
