## 部分真实值

野生区数据：`a0601_w01`、`a0101_w01`、`a0102_w01`，字段 `areaSceneName=t1`、`weight=50`，激活条件包括 `flag_Ev_m09_3200`、`flag_Ev_m06_4100`、`phase_condition`。`weight` 的含义需要对照使用处，不能直接认定为出现概率。

地图区域：`zoneID=a0101_w01` 对应 `areaName=farea_wild_a0101_w01`、`subAreaName=PLACENAME_wild_a0101_w01`、`fastTravelFlagId=flag_FastTravel_wild_a01_01`。关联需继续核查多条记录。

招式属性：`WazaCut → [75,163]`；`WazaDestruction → [2]`。这是原始招式 ID 列表，不等同于技能学习表。

头目设置：`MaxTalentValueCount=3`、`StrengthenValue=20`，仅确认字段和值，业务语义待核实。

## 执行完整导出

新增纯 Python 标准库脚本 `scripts/Export-ZA-Databases.py`，解析真正的 FlatBuffers Reflection schema 并按字段解码，不只检查 vtable 边界：

```powershell
python scripts/Export-ZA-Databases.py --repo . --workers 4 --samples 5 --require-all
python scripts/Export-ZA-Databases.py --only encounter spawner wild_zone field_location trainer
python scripts/Export-ZA-Databases.py --all-pairs --workers 8
```

输出 `.za-work/za-data/`：

- 每表 `<name>.json.gz`：全部解析结果，保留原始嵌套结构。
- 每表 `<name>.preview.json`：样本、数组数量。
- 每表 `<name>.records.csv`：根级记录、嵌套字段保留 JSON。
- `manifest.json` / `manifest.csv`：原始数据与 schema SHA256、根类型、成功/失败和错误原因。

配套 GitHub Actions `.github/workflows/za-real-data-export.yml`，推送独立文档分支时运行上述 20 组数据，并上传 Artifacts，保留 30 天。此工作流**不自动修改原始数据、不推送到 master**。`--all-pairs` 在本地完整 checkout 下使用；Actions 精选只 checkout 20 组，不能把它视为全仓库语义解析完成。
