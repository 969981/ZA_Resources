## Geometry
Single interleaved buffer verified for dual semantic layers: pm0006_52_00 fire stride68; pm0770_11_00 core and pm0770_51_00 energy/buster stride64. In single stream only, Layer is attribute set not buffer ordinal; multi-stream remains unsupported by exporter. V2.3 exports TEXCOORD_1 (and higher supported sets), normalized orthogonalized TANGENT when raw half4 W is near ±1 and length valid, raw _ZA_TANGENT_0/1 without rewriting source values. glTF only defines TANGENT, not TANGENT_1. Native color is preserved as COLOR_0 only when all components white (neutral multiply), otherwise _ZA_COLOR_0: native Unlit COLOR.r drives displacement, glTF COLOR_0 multiplies base color. No silent color loss or unproven multiplication. Normal Y, texture-transform tangent basis and native tangent sign parity remain unverified. Existing strict skin checks unchanged.
